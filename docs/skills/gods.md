# 神阵营战法（神示与落雷）

> 实现 `battle/skills_gods.py`；索引见 [index.md](index.md)。

## thunder_oracle 雷霆神谕（宙斯·自带·神谕）

- **效果**：己方全体【雷霆】（整局）：造成非落雷伤害后 70% 追加落雷——触发者智力
  100% 魔法伤害，每人每回合最多 3 次。
- **实现**：伪随机补偿（失败+9%、成功-7%、区间 30%~85%、4 次保底）；落雷 kind=
  `lightning` 不再触发雷霆（防递归）；宙斯性格·多情分神（oracle_suppressed 旗标）
  当回合全队雷霆不触发。
- **事件流**：status_apply(thunder)×3 → 触发时 status_tick + 子 damage(magic)。

## zeus_bolt 天雷击（宙斯·拆解·主动 50%）

- **效果**：对敌全体 200% 魔法伤害。
- **事件流**：skill_trigger(cast) → damage×N（逐目标，收局即停）。

## athena_aegis 埃癸斯圣盾（雅典娜·自带·神谕）

- **效果**（v3.2 改版）：己方全体【圣盾】（整局）：①受到伤害时 25% **反弹**——
  受伤归零，本应受伤害原样反弹给攻击者（固定特殊伤害，不可暴击、不可再被减免、
  不触发连锁）；①b 受控制后 25% 反制——对敌随机目标施加同种控制；
  ②己方统率最低者单次受伤超其受击前兵力 10% → 雅典娜为其回复（智力×0.9）。
- **实现**：反弹走引擎减免通道（`reflect_rate_bps`，damage.md §五）——与格挡/
  闪避的先后 = 状态施加顺序（其次技能格子顺序）；明睿·匠心旁骛
  （oracle_suppressed）当回合圣盾整体不生效（含反弹闸门 mitigation_gate）。
- **事件流**：反弹：damage(mitigation=reflect, amount=0) → status_tick(aegis_shield)
  → 子 damage(special)；反控/回复：status_tick + 子 status_apply/heal。
