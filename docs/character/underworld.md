## hades · 哈迪斯

- 冥界 / 皇 / 威权 / 冥域君临 · 冥河汲魂
- **商业钩子**：冥婚 CP 顶流；越打越肥的「王座吸血」成长核。

### 传记

冥界之主从不争锋于奥林匹斯，却把每一次交锋都变成贡赋——友军的统率如
细流汇入王座，敌军的智谋如冥河暗涌被抽干。损兵愈多，幽影愈厚；君临之下，
连呼吸都像欠下还不清的债。他与春后同场，便是付费皮与差分台词的标杆组合。

## medusa · 美杜莎

- 冥界 / 核 / 孤怨 / 石化凝视 · 蛇瞳一瞥
- **商业钩子**：珀尔修斯宿敌 CP；镜盾反杀与「蛇发女王」皮肤线。

### 传记

她曾是神庙里被亵渎的祭司，如今每一道目光都是迟来的审判——谁攻她，
谁便感到智谋被抽走、四肢被石化的寒。蛇瞳扫过之处，连怨念都凝成雕像；
偶尔，那诅咒也会照影回自身：孤怨者，终与镜中对视。猎手与圣盾，是她
故事里最烫的两条羁绊线。

## persephone · 珀耳塞福涅

- 冥界 / 半核 / 回春 / 冬春轮转 · 春芽
- **商业钩子**：冥婚女主；奇偶回合「春疗／冥击」节奏皮与 CP 差分。

偶有新绿从旧创里渗出。与哈迪斯同场，台词与立绘差分是长线付费核心。

## charon · 卡戎

- 冥界 / 普卡 / —（无性格） / 渡魂船费 · 摆渡
- **商业钩子**：减员收益「死亡税」；每亡一人三重回馈的阴郁辅助。

### 传记

冥河渡口的船夫从不问来者姓名，只问是否付得起魂价——有人倒下，他便
更清醒、更富有，并顺手把冥币般的治愈给最伤的一员，把诅咒般的潮击
打向最弱的一角。他的刃不华丽，却在每次伤害后贴上一张改不了期的账：
智减、伤增，像摆渡费永远还不清。

他是冥王麾下的终局之手——镰痕总落在最虚弱的颈上，刀落时连暴击都
更冷一分。死亡凝望不追喧嚣，只追那些被贴上诅咒的灵魂：标记一落，
他便从阴影里补上一击，像给名册盖章。与渡口同僚、冥王同列，他是
沉默的执行者。
