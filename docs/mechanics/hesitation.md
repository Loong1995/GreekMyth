# 犹豫（hesitation）

> 规则来源：任务书 5.3 + 决策 D-02；Phase 3 修订计次时点与窗口时序
> （`docs/prompts/phase3_battlecomplete.md` §三）。
> 实现：`battle/engine.py::_run_action_window / _settle_delayed_actions`；
> 状态：`battle/statuses.py::hesitation()`。
> 测试：`battle/tests/test_prepare_hesitation.py` + 交互矩阵。

## 1. 状态模型（Phase 3 修订后）

- kind=special、**不可叠层、可刷新**：重复施加只重置持续计次（`status_refresh`），
  stacks 恒为 1；`duration_rounds` 默认 2。
- payload `delay_rate_bps`：行动时的延迟判定率（默认 50%，施加方可配）。
  多来源刷新同一状态时以**首个实例**的判定率为准（实例绑定首个 def）。
- **计次时点（Phase 3 修订）**：与其他状态统一，在 **action_start 计次**
  （`count += 1`，`count > duration_rounds` 才摘除）。「持续 1 回合」=
  覆盖持有者**下一次**行动窗口（该窗 count=1 仍在身，可进延迟判定；
  再下一窗 count=2 到期）。超期移除后本窗新行动不再判定；但**已寄存的
  延迟行动不受影响**，照常在窗口最前补结算。
- 性格豁免：明睿/威权恒免犹豫判定；谋深按回合 roll 结果豁免（见 `traits.md`）。

## 2. 行动窗口时序（Phase 3 §三，④⑤ 互换后）

```
action_start
  ① 状态计次到期（含犹豫，统一前移）
  ② on_action_start 钩子（状态 + 性格窗口触发）
  ③ 犹豫延迟行动补结算（寄存行动照常释放，不再做犹豫判定）
  ④ 犹豫延迟判定（一窗一 roll）        ← 先判定
  ⑤ 准备型战法释放（release 免犹豫判定）← 后释放（互换）
  ⑥ 主动战法 → ⑦ 普攻（连击/追击）
```

1. 犹豫判定：**对本窗口「普攻 + 主动战法」整体 roll 一次**（`hesitation` 消费点）。
   全禁（冥锁/石化，无可延后行动）时不 roll、不消耗 RNG。
2. roll 中（延后）：**固定延后 1 回合**（第 N 回合的行动推迟到 N+1 回合窗口最前释放）：
   - 每个**通过触发判定**的主动战法发 `skill_trigger(kind=delayed, delay_rounds=1)`
     登记入延迟队列；触发判定照常消耗伪随机记账。
   - 普攻发 `skill_trigger(kind=delayed, skill_id=basic_attack)` 并登记。
3. roll 不中：正常行动。

## 3. 延迟行动补结算（窗口最前，N+1 回合）

- 登记条目在下一个行动窗口最前到期补结算：
  - 主动：若此刻被缄默/冥锁/石化（forbid_active）→ **作废**（静默）；
    否则按战法目标规则**重新选目标**（原目标阵亡自然换人；无合法目标作废），
    发 `skill_trigger(kind=release)` 并结算。准备型主动的延迟生效 = 进入准备。
  - 普攻：若此刻 forbid_basic → 作废；否则照常补打（正常 normal_attack 事件链）。
- **已登记的延迟行动不受犹豫刷新影响**：期间再次被施加犹豫只是刷新持续，
  上次犹豫延迟的行动仍按原定 N+1 回合释放。

## 4. 边界（交互矩阵逐格测试覆盖）

| 情形 | 结果 |
|---|---|
| 延迟期间施法者阵亡 | 延迟行动随 `hero_defeated` 清理作废（静默） |
| 延迟跨局边界 | 战时状态不跨局，随局清空作废 |
| 生效时点被缄默 | 主动作废、普攻照常补打 |
| 生效时点被冥锁/石化 | 主动与普攻一并作废 |
| 犹豫 × 冥锁同时在身 | 全禁无可延行动 → 不做犹豫判定（不消耗 RNG），犹豫照常计次 |
| 延迟期间犹豫被刷新 | 已登记行动不受影响，仍按原定 N+1 回合释放 |
| 追击 | 不独立受犹豫影响：普攻被延后则追击自然随之延后 |
| 准备型战法的 release | 不再做犹豫判定（已因准备延迟过，见决策 D-15） |
| 补结算的延迟行动 | 不再做犹豫判定（释放后才进入本窗口新判定） |
