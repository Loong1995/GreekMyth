#  客户端表演策略优化计划



## 一、项目备忘（原文保留）

SLG 类 2D 卡牌对战手游，全球上线，现代文娱视角下的希腊神话世界观，神/人/海/冥四阵营。
无大地图，主打个人竞技 rank 赛，通过立绘+战法组合深度+卡牌战斗爽感取得区分度，
吸引玩家将情感投射至英雄卡牌，提升养成欲望。
架构：服务器生成权威战报与反演事件流数据包 → 客户端执行窗口内动画反演。
服务端 battle（python 初版）：每武将最多一万兵，一队最多三武将。


---

客户端只将传过来的事件流进行播放表演，所有音效/图标/美术资源先随便占位。不论所有伤害/治疗/状态都在英雄头上飘字包括结算数量和对应技能名。

三个表演策略优先级，默认-》组优化-》特殊配置；
默认：
主动/追击/普攻/被动/状态类都设置组内默认策略，默认策略如下：
主动：武将释放时，若为群攻战法(选敌数量N=2/3)则以该战法为单元播放，移动至卡盘中心处，释放N个（等于战法选敌人数量）刀光/魔法光(取决于伤害类型)指向被打者，然后掉血；自带默认主动音效；若非群攻战法，则按照伤害段数每段为单元播放。
普攻：释放武将移动至被打者卡牌上表示近身，无普攻刀光特效；一个普攻就是一个播放单元，自带默认普攻音效；
追击：若该战法为群攻类，走主动群攻逻辑；若为单体类，走普攻逻辑以段数为单元打对应次数动画且自带默认追击音效；
被施加状态类：若武将被施加了状态，默认卡牌上方添加对应图标，状态消失则移除；但若被施加控制类状态(缄默/缴械/犹豫)，要将单独的状态图标放置在武将卡牌中央，后来的其他控制类状态继续放，但整体居中效果，若吃的控制实在太多放不开，则横着按行放置，确保不管多少图标都能放开；各个状态被施加时都播放该状态的默认音效，由于很多状态是跟伤害一起打出来的，这两音效不要重复播放；
特殊状态触发类：若武将被事件触发去打伤害，默认走主动逻辑，但是飘字要飘这个状态来源的战法名和伤害值，自带默认状态触发伤害类音效；该动画永远是其他播放单元执行完后再去播放。
已有的播放策略设置，若无和上面冲突的则不改逻辑策略本身，但可依据最新适配代码的写法实现。

以下是特殊配置级别，最高优先级。

## 二、神阵营特殊战法及表现

神谕类战法若有施加特效，是该战法施加完所有单位后，播放器一次给这些单位加上指定特效，也就是播放单元仍是整个神谕战法。
