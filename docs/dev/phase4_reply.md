# Phase 4 任务书回复文档（评审 + 初步提升计划）

> 回复 `docs/prompts/phase4_coreupgrade.md`。目标锚点：**商业付费价值吸引力最大化**。
> 本文档仅供确认，未开展任何实现。确认后按 §八 分期开工。

## 一、总评

方向判断正确：无大地图 SLG 的差异化只能压在"战斗即内容"上，
"赛前像配将、局中像主教练、战斗像神话动作片"三句话可以直接当 P4 的验收口径。
当前框架（服务器权威事件流 + 客户端 5 层播放）对这轮升级**兼容性很好**：
绝大多数新机制 = 新状态/新钩子 + 新事件类型（契约加法演进），
不需要动架构。真正的新增架构面只有两块：**经理人干预**（战报生成从"一次性
模拟"变为"分段模拟+中途注入指令"）和**势能→表现/音乐**（客户端新增一层
强度调度）。这两块是本轮的主要成本，也是主要卖点。

## 二、对任务书三个直接提问的回答

### 1. 围绕付费购卡动力，这些机制够不够、合不合理？

**够格但还差"最后一厘米"。** 现有清单（单挑/神谕连携/性格台词 + 新增经理人/
势能/连发/多普攻）解决的是"战斗好看、有变数"。付费购卡动力的完整链条是：
**看见（爽的演出）→ 想要（这张卡带来的爽是专属的）→ 值得（强度/稀有度）**。
清单对"看见"覆盖充分，对"想要"覆盖不足——建议补三个低成本高转化点：

- **专属演出绑卡**：皇/核卡必须有 1 个"只有它有"的演出锚点（宙斯全屏落雷
  cut-in、雅典娜反弹的盾面反光、哈迪斯后期变身滤镜）。当前演出配置库
  （PerformanceDatabase 三级策略）天然支持，只是资源级投入，逻辑零成本。
- **战报分享/名场面回放**：确定性战报是现成资产。终局自动截取"本场高光"
  （单挑获胜/最大单次伤害/势能满槽 cut-in）生成 15 秒回放，是拉新+晒卡的
  免费广告位。实现 = 客户端对已有事件流做二次剪辑播放，无服务端改动。
- **性格台词的收集面**：台词已有确定性轮换，建议每英雄加 2~3 条**低概率
  稀有台词**（如宙斯对特定女性英雄的专属互动已有雏形），图鉴里做成
  "语音/台词收集度"，直接服务养成欲望。

机制合理性上有两处要提醒（详见 §六 逐条）：
- 势能加分表里"打断敌人+2"当前核里只有石化/缄默打断准备一种来源，触发面窄，
  建议把"施加任意控制成功"也计 +1，否则该词条形同虚设。
- 连发无限（硬上限 7）+ 主动连发 +2 势能会让法系连发流的势能增速远超物理普攻流，
  cut-in 频率失衡；建议连发第 3 次起势能减半计（+1）。

### 2. 当前框架下实现/花费难度？

| 模块 | 服务端难度 | 客户端难度 | 结论 |
|---|---|---|---|
| 连发/多普攻/连击系 | 低（行动窗口循环加计数） | 低（复用现有单元播放） | 便宜，先做 |
| 站位 1~6 / 后排 | 低（position 已有，加"后排"谓词） | 低（棋盘 2×3 排布已支持扩展） | 便宜，先做 |
| 势能（个人） | 低（引擎记账+事件化 momentum_change） | 中（表现分级：音效/动画替换/cut-in 触发） | 核心卖点，性价比高 |
| 势能（全局→BGM） | 低（同上，队伍聚合） | 中（分层 BGM 方案见下） | 可行，方案见 §2-4 |
| cut-in（高伤/满势能） | 低（事件已含 amount，阈值判定可放客户端） | 中（立绘横切动画 + 打断当前节拍的插播规则） | 需定义"插播不阻塞"红线 |
| 经理人战术板 | **高**（战报生成改为分段：模拟 2 回合 → 出快照 → 等指令 → 续算；确定性/重放契约要扩展） | 中（战术板 UI + 倾向参数下发） | 本轮最大的架构工作 |
| 阵营合并（海+冥） | 低（roster 字段改动 + 文档） | 低 | 便宜 |
| 新武将/战法改版 | 中（量大：约 30 条战法重写/调参 + golden 重生成） | 低（演出配置补条目） | 体力活，按阵营分批 |

**经理人干预必须先定契约**：推荐"**指令窗口**"模型——战报按 2 回合分段生成，
每段末尾输出 `command_window` 事件（含双方状态快照）；玩家（或 AI 托管）提交
战术倾向（如集火目标/保守-激进滑杆/战法优先级偏置），作为下一段模拟的
`segment_directives` 输入。整局仍完全确定（seed + 全部指令序列可重放），
排位赛异步对战时对手侧由预设策略托管。这保住了"服务器权威+可重放"两条红线。

### 3. 有没有可升级的好点子？

除 §2-1 三点外，再给两个与现有机制强耦合的：
- **单挑升级为"约战"**：性格系统介入单挑——傲慢必应战、谋深可拒战、好战可
  主动叫阵，配台词。单挑从固定开局事件变成性格叙事的舞台，零新架构。
- **势能溢出技**：势能满槽（如 10 点）时该英雄下一次普攻自动升级为强化版
  （伤害 +30%、专属演出）。让势能有机制价值而不只是表现值，付费卡的强化版
  演出差异就是卖点。数值上等价于一个受控小增伤，不破坏平衡。

### 4. 音乐方案（你不懂音乐也能落地）

不要做"动态作曲"，做**分层混音（vertical layering）**，这是手游标准做法：

- 买/委托 **1 首 3~4 层的战斗 BGM**：层1 鼓底（恒放）、层2 弦乐律动、
  层3 铜管主旋律、层4 打击乐高潮层。各层同长度同 BPM，可无缝叠加。
- 全局势能 0~3 只放层1+2；4~7 淡入层3；8+ 淡入层4；单挑/cut-in 时瞬时
  全层+音量 duck（压低 BGM 突出音效）再恢复。
- 实现：Unity 原生 AudioSource 交叉淡变即可（每层一个 source 调音量），
  不需要 FMOD/Wwise；`SfxManager` 旁边加一个 `BgmLayerService`（~100 行）。
- 采购：Asset Store 搜 "vertical layered music / adaptive music pack"，
  或委托淘宝/Fiverr 音乐人"同一首曲子出 4 个 stem"，预算数百元级即可。
  占位期用现有单曲 + 音量/低通滤波随势能变化，逻辑先行。

## 三、逐阵营战法简评（平衡性 + 商业吸引力）

### 神（皇 ×2 + 核心结构合理，商业面最强）
- **宙斯**：连发 + 落雷每回合上限 3 次是对的。分神性格与对方女将数量挂钩，
  meta 上会催生"女团针对队"，话题性好，保留。
- **雅典娜**：任务书把圣盾从 25% 反制改为 **15% 反弹（免疫+反弹）**。注意：
  这与 2026-07-12 刚实现的反弹版（25%）只差概率参数，机制已就位，改参数即可。
  15% 配"免疫伤害"是合理的（免伤比原版强，概率该降）。
- **阿瑞斯**：全场血战（敌我易伤+暴击）是最好的"环境卡"设计，会被所有
  物理队带，半核定位低了，建议核。易伤乘区加法 & 100% 上限需在 formulas 固化。
- **赫尔墨斯/阿波罗/医神/尼刻/月神**：功能位齐整。尼刻新版"暴击机会"
  （首次伤害/治疗必暴）实现成本低；月影狩猎改"60% 优先锁后排"依赖站位系统先行。

### 人（缺连击系一环，本轮补齐）
- 连击系建议落在**新核心**上：推荐新增"**赫克托耳**"（特洛伊主将，与阿喀琉斯
  的宿敌叙事是免费的商业素材）：自带大型准备主动（任务书要的"三战关羽"位：
  准备 1 回合全体连击 buff + 高额兵刃，**连发不再准备当场释放**）。
  再把**阿塔兰忒提半核→核**（速攻+连击天然亲和）。
- **阿喀琉斯**：追伤计势能等同普攻 + 第 5 次触发 cut-in，标杆演出卡，保留。
- **珀尔修斯**改版（1~2 段、格挡上限 2 层、免疫石化、连发 35%）比旧版清爽；
  "新手赠送 + 全游戏唯一石化明牌反制"是教科书级的新手卡设计。
- **帕里斯**：暴击 +30% / 对 ≥50% 暴击目标必暴，针对面比旧版更锋利，保留话题卡。
- 喀戎移除：其"导师箴言"若无人继承会缺一个平加增益拼图，建议并给阿波罗拆技池。

### 海+冥（合并后 11 人偏多，建议核定 8~9 人上场池）
- **波塞冬**：震荡改"目标必须是受击者友军、上限 2 连"削得对（旧版 3 连
  在集火场景过强）。怒涛性格 + 记仇易伤是本阵营输出人格，核心定位成立。
- **哈迪斯**：幽影蔽体 50%→70% 上限 + 冥祭献统 5→10 点双吸（统+智），
  后期成长非常陡，建议保留但把"翻倍性格（威权）"排除在冥祭献统之外，
  否则皇卡滚雪球曲线会压过所有核卡。
- **美杜莎—珀尔修斯**反制闭环、**卡戎—阿瑞斯**跨阵营化学反应都是好设计。
- **塔纳托斯拆技"死亡凝望"**（被施加诅咒 60% 补 150% 魔伤）与卡戎拆技
  "摆渡"（伤害附带诅咒）构成组合技，注意诅咒施加频率——每次伤害都挂诅咒
  意味着凝望期望触发极高，建议诅咒不可刷新或凝望加每回合上限。
- 卡律布狄斯移除无异议（定位与刻耳柏洛斯重复）。

2. 雷霆：确认现行每回合 3 次上限（已有）；连发属性全新。
3. 战神怒火：易伤 +20%/暴击 +20% 数值版 + 易伤 100% 上限固化 + 战神之勇改武/速+20。
4. 十二试炼：50%→70%、反打 1 次→2 次独立 60%、吸血 +2%→+3%、新增每回合 4 次上限。
5. 冥域君临：蔽体 50→70、献统 5→10 且统智双收。
6. 三叉戟：连锁 3→2、目标限定受击者友军、新增己方 20% 闪避（现已有）。
7. 全新/重写：尼刻羽翼、月影狩猎、珀尔修斯、疾风女猎、致命一矢、七重牛皮盾、
   海嗣号角、魅音、六首撕咬、潮汐抚愈、渡魂船费、死神镰痕、三首噬咬、
   全部拆解战法新版、恐惧/诅咒/先攻点数等新状态。
8. 通用：连发属性（硬上限 7）、连击率体系、站位 1~6/后排谓词、势能记账与
   momentum 事件、经理人 command_window/segment_directives 契约、阵营合并、

9. 属性表：全表等级成长参数换新（1~50 级）。

## 五、战斗播放升级（客户端项）

- 飘字手调文档：输出 `docs/client/floating_text_tuning.md`——字号/颜色/字体/
  上浮曲线全部参数化到一个 ScriptableObject，Inspector 实时调；
  内置 3~4 款免费商用中文字体（思源黑体/得意黑/站酷系）作为主流手游风格选项。
- 势能表现分级表（0~3/4~7/8+ 三档：音效层、受击强化、cut-in 门槛）配置化。
- cut-in 规则：插播横幅不阻塞结算队列（复用单挑横幅通道），单回合至多 1 次，
  优先级 满势能 > 高额伤害 > 追伤第 5 次。

## 六、分期实施计划（确认后执行）

- **P4-A 服务端机制批**（先行，纯 battle/）：通用机制（连发/连击/站位/势能
  记账/新状态原语）→ 四阵营战法逐阵营重写 → 属性表 → golden/契约 1.4.0。
- **P4-B 客户端表现批**：新事件播放（momentum/cut-in/连发演出）→ 势能表现
  分级 → BGM 分层 → 飘字调参文档与工具。
- **P4-C 经理人批**（架构项，单独立项）：分段模拟契约 → 指令注入与重放
  验证 → 战术板 UI（先做滑杆+集火两个最小指令，画板式战术板后置）。
- 每批独立可验收、可上线；A 不阻塞现网，C 风险最高放最后。
