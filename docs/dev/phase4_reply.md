## 一、总评

方向判断正确：无大地图 SLG 的差异化只能压在"战斗即内容"上，
"赛前像配将、局中像主教练、战斗像神话动作片"三句话可以直接当 P4 的验收口径。
当前框架（服务器权威事件流 + 客户端 5 层播放）对这轮升级**兼容性很好**：
绝大多数新机制 = 新状态/新钩子 + 新事件类型（契约加法演进），
不需要动架构。真正的新增架构面只有两块：**经理人干预**（战报生成从"一次性
模拟"变为"分段模拟+中途注入指令"）和**势能→表现/音乐**（客户端新增一层
强度调度）。这两块是本轮的主要成本，也是主要卖点。

## 二、对任务书三个直接提问的回答

### 1. 围绕付费购卡动力，这些机制够不够、合不合理？

**够格但还差"最后一厘米"。** 现有清单（单挑/神谕连携/性格台词 + 新增经理人/
势能/连发/多普攻）解决的是"战斗好看、有变数"。付费购卡动力的完整链条是：
**看见（爽的演出）→ 想要（这张卡带来的爽是专属的）→ 值得（强度/稀有度）**。
清单对"看见"覆盖充分，对"想要"覆盖不足——建议补三个低成本高转化点：

- **专属演出绑卡**：皇/核卡必须有 1 个"只有它有"的演出锚点（宙斯全屏落雷
cut-in、雅典娜反弹的盾面反光、哈迪斯后期变身滤镜）。当前演出配置库
（PerformanceDatabase 三级策略）天然支持，只是资源级投入，逻辑零成本。
  - A: 意见不错，目前考虑的是宙斯施加后队友身上有闪电特效环绕，其他两个皇我不记得是什么特效了。现在进一步做增量，哈迪斯吸取队友时在队友头顶飘同时率显示哈迪斯头像，宙斯触发雷霆时在对面头顶生成宙斯头像并降落闪电，雅典娜的圣盾被触发时有特殊弹道反击效果。
- **战报分享/名场面回放**：确定性战报是现成资产。终局自动截取"本场高光"  
（单挑获胜/最大单次伤害/势能满槽 cut-in）生成 15 秒回放，是拉新+晒卡的  
免费广告位。实现 = 客户端对已有事件流做二次剪辑播放，无服务端改动。
  - A: 意见不错，遍历我方每个武将的所有行动窗给出单窗武将伤害量排行，排行第一的所在行动窗重新整理为高光片段，并以该武将头像预览和标识。
- **性格台词的收集面**：台词已有确定性轮换，建议每英雄加 2~3 条**低概率
稀有台词**（如宙斯对特定女性英雄的专属互动已有雏形），图鉴里做成
"语音/台词收集度"，直接服务养成欲望。
  - 图鉴系统后面再说。

机制合理性上有两处要提醒（详见 §六 逐条）：

- 势能加分表里"打断敌人+2"当前核里只有石化/缄默打断准备一种来源，触发面窄，
建议把"施加任意控制成功"也计 +1，否则该词条形同虚设。
  - 已修改加分表。
- 连发无限（硬上限 7）+ 主动连发 +2 势能会让法系连发流的势能增速远超物理普攻流，
cut-in 频率失衡；建议连发第 3 次起势能减半计（+1）。
  - 同上。



### 2. 当前框架下实现/花费难度？


| 模块             | 服务端难度                                                | 客户端难度                     | 结论           |
| -------------- | ---------------------------------------------------- | ------------------------- | ------------ |
| 连发/多普攻/连击系     | 低（行动窗口循环加计数）                                         | 低（复用现有单元播放）               | 便宜，先做        |
| 站位 1~6 / 后排    | 低（position 已有，加"后排"谓词）                               | 低（棋盘 2×3 排布已支持扩展）         | 便宜，先做        |
| 势能（个人）         | 低（引擎记账+事件化 momentum_change）                          | 中（表现分级：音效/动画替换/cut-in 触发） | 核心卖点，性价比高    |
| 势能（全局→BGM）     | 低（同上，队伍聚合）                                           | 中（分层 BGM 方案见下）            | 可行，方案见 §2-4  |
| cut-in（高伤/满势能） | 低（事件已含 amount，阈值判定可放客户端）                             | 中（立绘横切动画 + 打断当前节拍的插播规则）   | 需定义"插播不阻塞"红线 |
| 经理人战术板         | **高**（战报生成改为分段：模拟 2 回合 → 出快照 → 等指令 → 续算；确定性/重放契约要扩展） | 中（战术板 UI + 倾向参数下发）        | 本轮最大的架构工作    |
| 阵营合并（海+冥）      | 低（roster 字段改动 + 文档）                                  | 低                         | 便宜           |
| 新武将/战法改版       | 中（量大：约 30 条战法重写/调参 + golden 重生成）                     | 低（演出配置补条目）                | 体力活，按阵营分批    |


**经理人干预必须先定契约**：推荐"**指令窗口**"模型——战报按 2 回合分段生成，
每段末尾输出 `command_window` 事件（含双方状态快照）；玩家（或 AI 托管）提交
战术倾向（如集火目标/保守-激进滑杆/战法优先级偏置），作为下一段模拟的
`segment_directives` 输入。整局仍完全确定（seed + 全部指令序列可重放），
排位赛异步对战时对手侧由预设策略托管。这保住了"服务器权威+可重放"两条红线。

### 3. 有没有可升级的好点子？

除 §2-1 三点外，再给两个与现有机制强耦合的：

- **单挑升级为"约战"**：性格系统介入单挑——傲慢必应战、谋深可拒战、好战可
主动叫阵，配台词。单挑从固定开局事件变成性格叙事的舞台，零新架构。
  - 可以考虑，包括强制搦战。
- **势能溢出技**：势能满槽（如 10 点）时该英雄下一次普攻自动升级为强化版
（伤害 +30%、专属演出）。让势能有机制价值而不只是表现值，付费卡的强化版
演出差异就是卖点。数值上等价于一个受控小增伤，不破坏平衡。
  - 英雄满势能(8分)时我不清楚怎样的专属演出比较好，但不要引入额外的伤害或加成。我想可以考虑一些希腊语/陶绘风演出等，但完全不知道在当前演出框架下怎么不突兀又能上档次。若是精美演出，那我又没成本额外制作每个武将的该演出资源。



### 4. 音乐方案（你不懂音乐也能落地）

不要做"动态作曲"，做**分层混音（vertical layering）**，这是手游标准做法：

- 买/委托 **1 首 3~4 层的战斗 BGM**：层1 鼓底（恒放）、层2 弦乐律动、
层3 铜管主旋律、层4 打击乐高潮层。各层同长度同 BPM，可无缝叠加。
- 全局势能 0~~3 只放层1+2；4~~7 淡入层3；8+ 淡入层4；单挑/cut-in 时瞬时
全层+音量 duck（压低 BGM 突出音效）再恢复。
- 实现：Unity 原生 AudioSource 交叉淡变即可（每层一个 source 调音量），
不需要 FMOD/Wwise；`SfxManager` 旁边加一个 `BgmLayerService`（~100 行）。
- 采购：Asset Store 搜 "vertical layered music / adaptive music pack"，  
或委托淘宝/Fiverr 音乐人"同一首曲子出 4 个 stem"，预算数百元级即可。  
占位期用现有单曲 + 音量/低通滤波随势能变化，逻辑先行。
