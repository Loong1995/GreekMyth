## 一、任务书明确要求 Step A 提案的规则

### D-01 石化「受到伤害 +10%」所在乘区位置

【提案】放入**易伤乘区**（旧公式中已存在的「受到伤害增加」乘区，上限 +100%），
与其他易伤效果**加法叠加**后整体结算。
即：石化目标受到的伤害 = 正常伤害 × (1 + 10% + 其他易伤加成)，总易伤不超过 +100%。

理由：① 复用已标定乘区，不新增乘区、不破坏已校准的数值上限体系；② 加法叠加避免
「石化 × 其他易伤」乘法失控；③ 对物理/谋略/真伤一视同仁（石化是物理性的僵直，
真伤也应吃满 10%）。
备选方案（若希望石化更克制物理阵容）：仅对物理伤害生效——不推荐，规则复杂化。

【确认状态】✅已确认（2026-07-05）：按提案，放易伤乘区、加法叠加。

### D-02 犹豫状态完整规则

任务书 5.3 已定：可叠加、延后回合数 = 层数。旧笔记（readme.txt）写「不可叠加刷新」，
**以任务书为准**。以下补齐细则：

1. **判定时点**：武将行动窗口开始时，若身上有犹豫（N 层），对本次「普攻 + 主动战法」
   整体 roll 一次是否延后（几率 = 施加犹豫的战法配置的触发概率，默认 50%，可配）。
   roll 中则本次行动的普攻与主动战法都延后 N 回合生效；roll 不中则正常行动。
2. **消耗规则（人工修订版）**：犹豫**不因判定 roll 而清空**。与其他状态一致按
   回合计次消耗：武将每次行动窗口结算完毕后（若有延后生效的行动，先补结算延后行动，
   再计次）犹豫执行一次持续回合数递减，到期整体移除。持续期间每次行动都要做一次
   延后判定，延后回合数 = 当前层数。
3. **延后生效**：被延后的行动登记为「延迟行动」，在 N 回合后该武将行动窗口的最前
   执行（先补执行延迟行动，再进行当回合正常行动判定）。事件表达为
   `skill_trigger(kind=delayed, delay_rounds=N)`，实际生效时发 `kind=release`。
4. **边界情况**（配 Step B3 交互矩阵逐格测试）：
   - 施法者在延迟期间**阵亡** → 延迟行动作废，不生效（阵亡清理原则一致）。
   - 施法者在生效时点**被缄默/冥锁/石化** → 主动战法部分作废，普攻部分：缄默不禁
     普攻则照常补打，冥锁/石化则一并作废。
   - 原目标在生效时点**已阵亡** → 按该战法的目标规则**重新选目标**；无合法目标则作废。
   - 延迟**跨越局边界** → 战时状态不跨局，随局清空作废（任务书已定）。
   - 追击不受犹豫影响（追击挂在普攻命中后，普攻被延后则追击自然随之延后）。

【确认状态】✅已确认（2026-07-05）：第 2 条按人工修订——消耗改为「行动时
（延后生效结算后）执行回合计次」；其余按提案。

【二次人工修订（2026-07-05）】推翻「可叠加、延后回合数=层数」：
1. 延后**固定 1 回合**：第 N 回合被延迟的行动在 N+1 回合该武将窗口最前释放；
2. 释放后才进入新一轮犹豫判定（补结算的行动本身不再做犹豫判定）；
3. 重复施加犹豫为**刷新不叠层**（重置持续计次，stacks 恒为 1）；
4. 已登记的延迟行动不受后续犹豫刷新影响（仍按原定 N+1 回合释放）。
已按此实现并更新 hesitation.md 与全部相关测试。

### D-03 单挑胜负公式与拒绝几率公式

任务书约束：按武力差随机，武力差 ≥10 时必定结果。设 `d = 高武力 - 低武力`（d ≥ 0）。

【拒绝几率（已定）】低武力方拒绝概率 = `d × 8%`，d≥10 时封顶 **80%**
（即武力差 10 以上仍保留 20% 接受概率，为单挑演出保留出场机会）。

【胜负公式（原定 2026-07-05）】接受后，高武力方胜率 = `50% + d × 5%`，d≥10 必胜。

【惩罚与频次（已定）】负者四维立即 -10。**一个系列只单挑一次，发生在第 1 局开局**；
惩罚**只存在第 1 局**（不带入第 2 局及以后——事件流中以 `attr_change(scope=game)`
表达）。第 2 局起不再判定单挑。

【确认状态】✅已确认（2026-07-05）：拒绝封顶 80%（差 10 以上保留 20% 接受）；
单挑仅第 1 局一次、惩罚仅第 1 局有效。

**【2026-07-21 演进】** 资格改为「武力>智力」参赛；序号对位 + S1/S2 羁绊初对；
武力差线性入池（0→90%、≥50→5%）；候选按羁绊再武差取一对真决斗。空池则固定
叫阵-拒绝剧本。交锋段数 `clash_cutins` 加法下发。**废除性格约战机械表**
（必应战/强制搦战/拒绝率加成/低武入场）。**胜负改**：高武力方胜率 =
`50% + d`（百分点），**d≥50 必胜**（原 d×5% / d≥10 废止）。细则见 `mechanics/duel.md`。

### D-04 连携触发概率 k

任务书 5.4：主将神谕释放后，两副将自带主动战法各有 k 几率立即释放。

【已定】k = **70%**（暂定值，平衡期可调），固定配置于全局规则（`mechanics/assist.md`），
不随属性浮动。两副将各自独立 roll；触发顺序按站位顺序；准备类战法无需准备直接释放

行动时，同一主动战法**仍可再次正常释放**。

【确认状态】✅已确认（2026-07-05）：k=70%；连携后本回合仍可继续释放同战法。

## 二、旧 core 数值/规则疑点（按任务书 4.3 记录，不擅自修改）

### D-05 兵力系数分母用全局 10000 而非武将自身上限

【提案】保留旧公式字面行为（10000 固定分母、不截断）迁移。

【确认状态】✅已确认（2026-07-05）：保留、**不加截断**——超编 NPC 打出超高兵力
系数是设计意图（就是要让超编 NPC 有压迫感）。

【提案】以任务书为准：**单局打满即平局**，剩余兵力只用于系列打满 7 局仍平时的
系列级展示（系列平局不强判胜负）。旧行为不迁移。

【确认状态】✅已确认（2026-07-05）：按新任务书执行。

【修订】（2026-07-22，用户指示）：单局默认上限 **999**（打到主将阵亡；

（追击的组根指回普攻的伤害事件）。客户端两种粒度均零计算。论证见契约 §3.2。

【确认状态】✅已确认（2026-07-05）。

### D-14 三条省体积规则

空相位不发 phase_start；无状态变化不发事件（免疫/拒绝刷新静默）；局末批量状态清理
不逐条发事件（由 game_end 语义覆盖）。若策划要求「抵抗/免疫」有演出，后续加法式
新增 `status_resisted` 事件类型即可，不破坏契约。

【确认状态】✅已确认（2026-07-05）。

### D-15 准备中的武将仍可普攻；release 免犹豫判定

准备型战法只锁「该战法的效果结算」，武将准备期间行动窗口照常普攻（旧 core 蓄力语义）。

【确认状态】待审阅（已按此实现）

### D-16 连携的随机与记账口径

连携 roll（k=70%）用**普通随机**、不走伪随机补偿、不触碰该战法的伪随机记账
（D-04「不占用正常释放机会」的自然延伸——记账也不占用）。副将准备型主动被连携时
跳过准备直接结算 release 效果（任务书已定）。

【确认状态】待审阅（已按此实现）

### D-17 追击的两条边界

① 普攻该击已把目标打死 → 追击不 roll 不触发（无可追之敌）；② 攻击者在普攻结算后、
追击分发前获得 forbid_basic/forbid_pursuit（如美杜莎凝视反制石化）→ 追击被封锁。
「禁普攻即禁追击」贯穿整个结算窗口而非仅窗口开始快照。

【确认状态】待审阅（已按此实现）

### D-18 海神三叉戟（旧 core 仅描述）震荡链判定口径

【确认状态】✅已人工修订确认（2026-07-05）：无视统帅 = 对方统帅置 0
