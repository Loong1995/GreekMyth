# 数值等价统计验证结论（任务书 4.3 / Step B2 验收项）

日期：2026-07-05　执行工具：`battle/tools/numeric_equivalence.py`（可直接
`python battle/tools/numeric_equivalence.py` 复跑，结果落
`battle/tools/out/numeric_equivalence_result.txt`）

## 1. 方法

- **机制交集**：新旧 core 都完整实现的机制只有「3v3 纯普攻对抗」（旧 core 战法
  多为半成品，新 core 正式战法在 B3），因此用同一套 3v3 无战法阵容做对比。
- **样本**：种子 1..1000，各 1000 场（旧 core `battlecore.api.run_battle`
  8 回合单局；新 core `battle.simulate` 取系列第 1 局）。
- **口径对齐**：旧 core 回合耗尽按剩余兵力多者判胜；新 core 第 1 局 round_limit
  平局时按同规则事后判定（仅用于对比，不影响正式规则 D-06）。
- **为何是统计对比而非逐值对比**：两边 RNG 消费顺序不同（架构重写：如旧 core
  经 timing 心跳消费、新 core 按行动窗口直线消费），单场事件不可能逐值一致；
  但所有公式（伤害/拆分/损耗/先手概率/受击权重）逐值迁移且有单测锚定
  （`battle/tests/test_formulas.py`，期望值直接取自旧 core 标定用例），
  因此分布统计必须收敛到一致。

## 2. 结果（1000 场）

| 指标 | 旧 core | 新 core | 差异 | 容差 | 判定 |
|---|---|---|---|---|---|
| A 队胜率 | 30.6% | 31.0% | 0.40pp | ≤4pp | OK |
| B 队胜率 | 69.4% | 68.9% | 0.50pp | ≤4pp | OK |
| 平局率 | 0.0% | 0.1% | 0.10pp | ≤4pp | OK |
| 场均总伤害 | 15745.7 | 15728.5 | 0.11% | ≤2% | OK |
| 场均剩余兵力 | 44254.3 | 44271.5 | 0.04% | ≤2% | OK |

（两队独立 1000 场样本的胜率标准误约 ±1.5pp，观测差异 0.4~0.5pp 远在抽样噪声内。）

## 3. 结论

**PASS。** 新 core 在普攻主循环（伤害公式、兵力三池、伤兵损耗、先手概率、
受击率加权选人、终局判定）上与旧 core 统计等价；结合公式单测的逐值锚定，
认定 B2 数值迁移无失真。

## 4. 已知且有意的行为差异（不影响本验证）

1. 新 core 平局残血续战（系列制，D-06）；旧 core 单局按剩余兵力强制分胜负。
2. 新 core 仅主将阵亡判负；旧 core 另有全队覆灭条件（逻辑上被主将条件蕴含）。
3. 新 core 伤害事件携带三池 before/after 全量快照；口径换算已在工具内对齐。
4. 状态/战法/治疗等 B2 新机制旧 core 无可用对照组，由公式单测
   （标定值 500/400/1073 等）+ 结构/边界测试覆盖。
