## 一、厄里斯 · 对位三连



### 1.1 面板草案（可调）

（性格数值未定死，落地前可改成纯叙事弱修正或砍掉失手。）

### 1.2 `eris_discord` 纷争对位（自带·**被动**）

- **效果**：轮到厄里斯自己的行动窗口时，在其**主动/普攻之前**，依次打出三道
「对位」伤害（同一行动窗、同一播放单元）：
  1. **武对武**：我方武力最高 → 敌方武力最高，**100% 兵刃**；
  2. **智对智**：我方智力最高 → 敌方智力最高，**100% 谋略**；
  3. **速对速**：我方速度最高 → 敌方速度最高，**100%**——该我方单位
    **武力 ≥ 智力则兵刃，否则谋略**。
- **实现要点**（落地时）：
  - 挂 `on_action_start`（或等价：行动窗内、主动判定之前）。
  - 选最高：有效属性；**并列取站位更小**（与战神之勇等同口径）。
  - `source_id` = 出手的那名**我方单位**（借手）；`skill_id` = 本战法。
  - **不受缄默/缴械/石化影响**：这不是主动也不是普攻；石化只禁主动+普攻，
  行动窗仍会开，本被动仍结算（见下「关于 skipped」）。
  - 某一维双方缺存活单位 → 该道不发事件；序固定武→智→速。
- **事件流**：`action_start`(厄里斯) → `damage`×1~3 →（若未禁）主动/普攻照常。



### 1.3 `eris_strife` 挑拨（拆解·**主动 55%**）

- **效果**：同上三道对位，系数 **80%**。
- **实现**：`trigger_rate_bps=5500`；主动槽；**缄默/石化**（`forbid_active`）禁止。
- **事件流**：`skill_trigger(cast)` → `damage`×1~3。



### 1.4 关于 `skipped`（引擎事实，纠正旧稿）

- **有** `action_start.skipped`：当本窗「普攻被禁，且（主动被禁或根本没装主动），
且没有到期的准备释放/延迟行动」时标 `true`，并用于选一条全禁台词。
- **不是**「整窗作废、钩子不跑」。石化 = `forbid_active`+`forbid_basic`，
表现就是本窗打不出主动和普攻；`on_action_start` **仍执行**。
- **冥锁** `ming_lock`：仅有建造器 + 交互单测，**现行武将池战法不施加**；
产品描述勿当现役机制写。全禁体验以**石化为准**即可。

### 2.2 新状态 `underworld_burn`【冥火】


| 项    | 值                                                                     |
| ---- | --------------------------------------------------------------------- |
| kind | debuff                                                                |
| 持续   | 见战法（建议 2~3 行动窗计次）                                                     |
| 叠层   | 可叠最多3层；**可刷新**（负面例外，与诅咒同思路：方便「持续烧]）                                   |
| DoT  | `dot_rate_bps`：**6000（60%）**；`ROUND_START` tick；来源智力 vs 持有者统率；**可暴击** |
| 控制   | 无（纯烧）                                                                 |
| 清理   | 来源阵亡清；与现有 DoT 规则一致                                                    |


客户端：控制大图标占用；冥火走中央状态图标（无 CFXR 光环）；
冰锢光环 **CFXR3 Ice Shield** 卡面下方。势能火另见 `momentum_fire`。

### 2.3 `hecate_torch` 三火炬（自带·**被动**）

- **效果**：准备阶段自身获【岔路火种】（整局载体）。持有者对敌造成**实际魔法伤害**后，
对目标施加/刷新【冥火】**2 回合**。每人每回合最多因本效果刷新 **2 次**
（防多段技能刷爆）。
- **实现**：`on_damage_dealt`；`amount>0` 且 `damage_type=magic`；
不计 `special`/DoT 自触发（冥火 tick 不再挂冥火）。
- **事件流**：prepare `status_apply`(载体) → 触发时 `status_apply/refresh`(冥火)。



### 2.4 `hecate_pyre` 燔祭（拆解·**主动 50%**）

- **效果**：对敌随机 **2** 人各 **160% 谋略**，并各施加/刷新【冥火】**3 回合**；
若目标已有冥火，本次伤害 **额外 +15%**（`extra_damage_up`）。
- **实现**：`trigger_rate_bps=5000`；选人受击率加权。
- **事件流**：`skill_trigger` → `damage` + `status_apply`(冥火) ×2。

## 三、卡吕普索 · 冰锢



### 3.1 面板草案


| 档位  | 性格（草案）                                                | 武       | 智       | 统       | 速       |

### 3.2 新状态 `freeze`【冰锢】


| 项     | 值                                                                             |
| ----- | ----------------------------------------------------------------------------- |
| kind  | **control**                                                                   |
| 禁制    | `forbid_active` + `forbid_basic`（**不能放主动、不能普攻**；追击随普攻禁）                       |
| 打断    | 施加成功即打断目标准备中战法（凡 `forbid_active` 皆然，同缄默/石化）                                   |
| DoT   | `None`                                                                        |
| 持续    | 见战法                                                                           |
| 叠层    | 不可叠不可刷新（控制默认）；同目标重复施加 → **静默拒绝**                                              |
| 与石化关系 | 禁制键相同（双禁），**无**石化那 +10% 易伤；独立 `status_id` + 客户端大图标；可叠 DoT                     |
| 交互    | 控制不冻结 DoT；被冰锢时 `action_start` 可标 `skipped`（与石化同条件）；光环 **CFXR3 Ice Shield** 卡面下方 y≈−0.3 |


> 语义：冰锢 =「冻住手脚 + 寒气噬体」；无全禁以外的额外易伤。



### 3.3 `calypso_detain` 奥杰吉厄羁留（自带·**主动 45%**）

- **效果**：对敌方**速度最高**存活单位施加【冰锢】**2 回合**，并立即造成
**140% 谋略**（先伤害后上控，或先控后伤——草案：**先伤后控**，与多数控技一致需确认）。
- **实现**：`trigger_rate_bps=4500`；选速最高，并列小站位。
- **事件流**：`skill_trigger` → `damage` → `status_apply`(freeze)。



### 3.4 `calypso_rime` 霜潮（拆解·**主动 40%**）

- **效果**：对敌随机 **1~2** 人（等概率）各 **120% 谋略**，并有40几率【冰锢】**1 回合**。
- **实现**：`1 + rand_index(2)`；`trigger_rate_bps=4000`。
- **事件流**：`skill_trigger` → (`damage` + freeze)×N。
