# Skills

本文档记录当前 BattleCore 已配置技能的自然语言描述。

约定：

- 每次新增 skill 时同步更新本文档。
- 描述风格参考 SLG / 三战类战法文本。
- 配置细节仍以 `battlecore/config/skill_files.py` 和 `config_db.py` 为准。

## Basic Attack

普通攻击。

武将率领部曲向敌军发起常规攻势，对敌军单体造成一次兵刃伤害。此攻击不依赖神力、秘术或战法谋划，而是战场上最基础的军阵压制；伤害受攻击者武力、当前兵力编制完整度以及目标统率影响。

## 戈耳工凝视

主动战法。

美杜莎的阴影掠过战场，戈耳工之眼在敌阵中睁开；被凝视者不仅会承受来自古老诅咒的谋略打击，更有可能被冥府之锁缠缚，陷入无法行动的恐惧之中。发动后对敌军两名单体分别造成谋略伤害，并对每名受击目标独立判定是否施加【冥锁】，使其无法发动主动战法与普通攻击。

## 德尔斐启示

神谕技能。

德尔斐的圣火映照战场，阿波罗的预言穿透迷雾。战斗准备阶段，神谕持有者为己方全体揭示胜利征兆，使受神谕庇护者在命运指引下展现更强的力量、谋略、统御与身法。己方全体获得【神示】，四维属性提高，持续整场战斗。

## 阿斯克勒庇俄斯圣谕

神谕技能。

医神的蛇杖在战场阴影中低鸣，阿斯克勒庇俄斯的圣谕守护着濒危之人。战斗准备阶段，神谕持有者为己方全体施加【蛇杖庇护】；战斗中，每当受庇护者承受创伤，神圣医术便有 40% 概率回应伤痛。基础治疗量 = 受击者最大兵力 1% + 神谕持有者智力 × 0.6；治疗只能恢复伤兵。

## 雷霆神谕

神谕技能。

宙斯的雷云笼罩战场，雷霆在奥林匹斯之巅轰鸣。战斗准备阶段，神谕持有者为己方全体施加【雷霆】；拥有雷霆庇护的单位造成任意非落雷伤害后，有 60% 概率对本次受击目标追加一次谋略落雷，每名英雄每回合最多触发三次。落雷伤害系数 100%，使用**触发者自身**智力计算；落雷本身不会再次引动落雷。
